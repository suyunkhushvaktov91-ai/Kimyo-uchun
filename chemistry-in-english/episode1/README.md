# Chemistry in English — Episode 1: What Is Everything Made Of?

A ~10-minute solo-narrated YouTube lesson for people learning English (especially Uzbek speakers) through chemistry. It starts from "what is matter?" and zooms into the atom: the nucleus, protons, neutrons, electrons, the atomic number, elements, electron shells and molecules. Along the way it teaches **12 vocabulary words**, with Uzbek translations.

Visuals come from **Atom Studio**, a single HTML page with animated scenes. Each scene goes forward one step at a time, matching the cues in the script.

## Files

| File | What it is |
|------|------------|
| `script/narration.md` | Full narration, scene by scene, with Atom Studio cues `[scene.step]` |
| `script/scenes/s1.txt` … `s6.txt`, `extra.txt` | Clean text of each scene for reading while recording (no cues) |
| `vocabulary.md` | The 12 words: pronunciation, Uzbek, definitions, example sentences |
| `quiz.md` | 12-question quiz + bonus, with answers (Q1–5 are the on-screen quiz) |
| `atom-studio/index.html` | The animated Atom Studio page — one self-contained file, works offline |
| `production/recording-guide.md` | How to record and clean up the voice |
| `production/montage-capcut.md` | How to capture the visuals and edit in CapCut |
| `production/youtube.md` | Title, chapters, description, tags, upload settings |
| `production/checklist.md` | Step-by-step checklist from preparation to publishing |

## How to record and edit (short version)

1. **Prepare** — read `script/narration.md` out loud, practise the words in `vocabulary.md`.
2. **Record the voice** — one file per scene, reading from `script/scenes/sN.txt`. Slow and clear, about 115 words per minute. Clean up in Audacity. → `production/recording-guide.md`
3. **Capture the visuals** — open `atom-studio/index.html` in Chrome or Edge, press `F` (fullscreen) and `H` (hide panel). Play your voice track in headphones and press `→` at each cue while OBS records the screen. → `production/montage-capcut.md`, step 1
4. **Edit in CapCut** — put the scenes in order, sync, add quiz cards, captions, quiet music, then export 1080p. → `production/montage-capcut.md`
5. **Publish** — title, chapters, description and tags are ready in `production/youtube.md`. Go through `production/checklist.md` before you press Publish.

## Atom Studio controls

| Key | Action |
|-----|--------|
| `1` – `6` | Open scene 1–6 (starts at step 0) |
| `→` / `Space` / click | Next step (when the panel is hidden, a click also goes to the next step) |
| `←` | Previous step |
| `R` | Replay the current step's animation |
| `0` | Free mode: any element from H to Mg (`↑` / `↓` to change) |
| `H` | Hide / show the control panel and mouse cursor (hide it for recording) |
| `U` | Uzbek lines on / off |
| `L` | Pointer labels on / off |
| `P` | Pause the orbit motion |
| `F` | Fullscreen |

URL shortcuts: `index.html#3.2` opens scene 3, step 2. Add `clean` to hide the panel: `index.html#4.6clean`.

The page draws at 1920×1080 and scales to any window. It needs no internet connection and no installation.
